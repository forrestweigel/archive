# Archive brand

Archive’s primary visual reference is the owner-supplied logo below. The official Magic website remains a secondary reference for website composition and promotional hierarchy.

![Archive logo with the tagline SHUFFLE. SPLIT. PLAY.](../public/brand/full-no-background.png)

## Logo

The supplied lockup contains a vermilion stacked geometric symbol on the left, a black sculptural serif ARCHIVE wordmark, and the tagline above the wordmark. Its bold silhouette, compact typography, and clean geometric symbol guide the visual style.

Use the owner-supplied assets unchanged, served from `/brand/`:

| Asset | Use |
| --- | --- |
| `full-no-background.png` | Full transparent lockup with symbol, wordmark, and tagline; footer and spacious brand placements. |
| `icon.png` | Standalone symbol; navigation icon and application favicon. |
| `title-with-tagline.png` | Wordmark and tagline; reference card and other compact brand materials. |
| `title.png` | Wordmark alone; navigation beside the symbol. |
| `archive-logo-lockup.png` | Original white-background reference image, retained for provenance. |

Preserve aspect ratios, colors, internal spacing, and arrangements. Leave generous space around each logo. Do not redraw, distort, add effects to, or replace the wordmark with a font. The transparent wordmarks are black; place them on white or compatible light surfaces. Transparency does not make them suitable for black backgrounds. Scale tagline-bearing variants only while the tagline remains readable.

Use meaningful alt text such as “Archive — Shuffle. Split. Play.” when the logo identifies the brand. A linked homepage logo should have an accessible name identifying Archive’s homepage.

## Tagline

**SHUFFLE. SPLIT. PLAY.** is the permanent brand tagline. Preserve uppercase lettering, word order, and periods, independent of the Alpha release designation.

Use it prominently on the homepage and brand materials, including reference cards when space permits. When typeset separately, use Gotham Narrow Bold or Black. Avoid repeating it directly beside the supplied lockup, which already includes it. Keep setup instructions and the format explanation readable alongside the tagline.

## Typography

- Headings and display copy: Gotham Narrow; Black (900) for primary headings and Bold (700) for supporting headings.
- Body and supporting interface text: Open Sans.
- Logo wordmark: supplied artwork. Its serif lettering is a brand mark, not a replacement for the heading font.

Load Gotham Narrow from `app/fonts/GothamNarrow-Bold.woff2` and `app/fonts/GothamNarrow-Black.woff2` through `next/font/local`.

## Color and composition

The application’s canonical colors are foreground **#000000**, background **#FFFFFF**, and primary **#C8371C**. Use these values in the application theme. Supporting muted surfaces and borders use neutral grays. Primary buttons use white text. Maintain accessible contrast for text and controls.

Build around bold headings, strong silhouettes, generous space, clear calls to action, and simple geometric diagrams. Contrasting dark and light sections and editorial resource grids can follow the Magic website reference, while the logo determines Archive’s branding. Keep rules surfaces uncluttered and readable.

## Additional useful exports

The supplied transparent PNG variants cover current application placements. SVG versions and a light wordmark variant for dark backgrounds remain useful future exports. Use the supplied assets until those variants are available; do not manufacture substitutes or use proprietary Magic assets.
